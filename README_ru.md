Легковесная минималистичная утилита для системного трея Windows с автоочисткой корзины и аккуратным темным интерфейсом.

---

## Особенности
* **Работа в системном трее:** Работает тихо в фоне, не занимая место на панели задач.
* **Минималистичный темный интерфейс:** Удобная панель настроек на встроенном `tkinter` с минимальным потреблением ресурсов.
* **Умная автоочистка по времени:** Рассчитывает разницу дат с момента последней очистки. Если компьютер перезагрузится, таймер не собьется.
* **Кастомные иконки:** Поддержка ваших собственных файлов `empty.ico` и `full.ico` для отображения состояния корзины.
* **Быстрое управление:**
  * Двойной клик ЛКМ по иконке трея мгновенно очищает корзину.
  * Меню по ПКМ: **Очистить сейчас**, **Открыть корзину**, **Настройки** и **Выход**.
* **Чистота системы:** Настройки сохраняются в защищенную папку `%appdata%\MiniBin`, не создавая мусор в корне с программой.

##⚠️ Предупреждение антивируса (Ложное срабатывание)
> Защитник Windows или другие антивирусы могут ошибочно заблокировать скомпилированный `MiniBin.exe` (например, выдав предупреждение о трояне). Это **стандартное ложное срабатывание**, вызванное особенностями упаковки Python-скрипта через PyInstaller. MiniBin полностью безопасен. Чтобы программа работала корректно, просто добавьте папку с приложением в исключения вашего антивируса.
